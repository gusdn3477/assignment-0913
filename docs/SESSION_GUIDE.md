# 기능 세션 가이드

## 공통 지시
사용자가 승인한 구현: TypeScript strict + Next App Router + Tailwind/cn + shadcn + TanStack Query + Zustand. 6시간 내 필수 기능/검증/문서, 기능별 독립 세션과 워크트리, type(scope) 커밋. 기능 목록은 유동적입니다.

사용자 추가 지시 원문: “중간 중간 문서를 업데이트 해줘서 새 세션에서 뭘 하면 될 지 바로 참고할 수 있게 해줘”.

## 작업 방법
- 반드시 배정된 워크트리에서만 명령과 편집을 수행합니다. 루트 작업 폴더는 통합 담당자의 소유입니다.
- 먼저 STATUS.md → DECISIONS.md → 해당 docs/tasks 문서를 읽습니다.
- 공유 node_modules 심볼릭 링크를 사용하며 의존성을 직접 변경하지 않습니다.
- 기능 범위에 맞는 구현과 의미 있는 테스트를 함께 수행합니다.
- 실제 받은 작업 지시 원문, 구현 요지, 발견한 문제, 검증 명령/결과, 채택/수정 이유를 docs/records/<feature>.md에 기록합니다.
- 작업 문서에 완료·남은 사항·인계 정보를 갱신합니다.
- feat(scope), fix(scope), test(scope), docs(scope) 형식으로 필요한 파일만 커밋합니다.
- 최종 보고: 절대 워크트리 경로 / 브랜치 / SHA / 검증 / 미완료 사항.
- 새 기능은 현재 세션을 재사용하지 않고 새 세션으로 넘깁니다.

## 공통 인터페이스 변경
다른 담당자의 코드를 예상해서 바꾸지 말고 통합 담당자에게 필요한 변경을 전달합니다. 수정 영역이 겹치는 병렬 작업은 시작하지 않습니다.
